# ORB v3 PAPER SANDBOX - dashboard

Password-protected (StaticCrypt) dashboard for an independent ORB v3 paper-trading
sandbox. Paper Alpaca account only - **no real money**.

- Universe: the same 14 NDX symbols and rules as the LIVE ORB v3 strategy
- Separate from `orb-v3-live` and from every other bot on the machine
- Generated by `orb-paper-sandbox.ps1 -Job Dashboard`

`index.html` is encrypted at rest with StaticCrypt. The password is never stored here.
